# Speech-to-Text API

## Definition

A speech-to-text API is an application programming interface that accepts audio
or video input and returns a text transcript. Some services also return timing,
speaker, translation, or confidence metadata alongside the transcript.

## Context and Usage

Developers use speech-to-text APIs to build meeting note tools, podcast search,
video captioning workflows, call-center analytics, and accessibility features.
In a Daytona workspace, a speech-to-text API can be tested from a reproducible
project environment while credentials stay in local environment variables.
